# Caves and Dungeons для LANMinecraft

Производная от [Caves and Dungeons 1.4 автора TerragasT](https://www.curseforge.com/minecraft/modpacks/caves-and-dungeons/files/6164816): Minecraft 1.20.1, Forge 47.3.7, Java 17. В библиотеке LANMinecraft сборка называется **Caves and Dungeons** и устанавливается в одноимённую папку.

## Мир «Шахты с Модами»

Версия для лаунчера добавляет собственный пресет `caves_and_dungeons:modded_mines` с названием **Шахты с Модами**. Его измерения соответствуют обычному авторскому миру сборки: сохраняются пещерные биомы установленных модов, подземный бункер, опасное солнце и закрытый Незер. Это не новый алгоритм полностью пещерной планеты.

При создании нового мира доступен только этот пресет, включая расширенный список с Shift и повторное создание. Загрузка уже существующих и импортированных миров не ограничивается. Не удаляйте helper `cad_world_type_lock`: он поставляет сам пресет и проверяет выбор перед созданием мира.

Пресет создан для этой поставки по запросу пользователя. Его нельзя выдавать за восстановленную реализацию из ролика Иванчелы: в публичных экспортах 1.1–1.4 и в реестре исходного клиента 1.4 отдельный пресет «Шахты с Модами» не найден. [Официальный пост Иванчелы](https://t.me/ivanchelayt/545) связывает «Ультра Пещеры» с Alex’s Caves; [примечания первого выпуска](https://www.curseforge.com/minecraft/modpacks/caves-and-dungeons/files/5171672) сообщают об отличиях от отснятой версии. Точные настройки и сид отснятого мира не установлены.

## Изменения исходной сборки

Все 93 авторских JAR и три overrides закреплены в историческом `tools/upstream-lock.json`. Существующие авторские рецепты и JAR-ресурсы сохранены; отдельные ресурсы helper дополняют русские переводы достижений. Единственная замена исходного JAR по отдельному запросу пользователя: Xaero’s World Map 1.39.2 обновлена до 1.47.0 для Forge 1.20.1; вложенная XaeroLib 1.7.3 добавляется вместе с ней. Точные старые и новые SHA256 и проверка необходимости Safety описаны в `tools/UPDATE-NOTES.md` и активном lock. Собственный helper поставляется дополнительно. Для русского квестбука добавлены FTB Quests, FTB Library и FTB Teams без обновления общих библиотек; точные версии и Safety-проверка описаны в `tools/quests/FTB-REVIEW.md`.

Активная поставка описана в `tools/distribution-lock.json`. Исторический импорт не является способом восстановления поверх изменённой поставки. Не запускайте его для отката активных файлов.

## Русские достижения и квестбук

При выборе русского языка все зарегистрированные достижения доступны на русском, включая скрытые после их открытия. Переводы охватывают 567 исходных определений. Недостающие 210 строк встроены в helper 1.1.0; вручную включать ресурспак не нужно. Английский язык сохраняет исходные тексты.

Книга FTB Quests «Путь сквозь пещеры» содержит четыре основные главы: жизнь под землёй, снаряжение, исследование пещер и дорога в Край. Дополнительные разделы ведут по достижениям отдельных модов. Структура короткого маршрута и дополнительных веток взята за пример у TerraFirma Rebirth 2, тексты написаны для рецептов этой сборки. В книге нет наград, команд, выдачи опыта или расходования предметов. Ранее выполненные достижения учитываются автоматически; закрытый Незер не требуется для основного маршрута. Недоступные при авторских ограничениях дополнительные достижения явно отмечены.

Книга открывается кнопкой FTB Quests в инвентаре или назначенной клавишей мода. Исходники и проверка: `tools/quests/README.md`, переводы: `tools/russian-advancements/README.md`. Управляемый путь `config/ftbquests/quests/**` обновляет книгу в установленных экземплярах; изменённые пользователем прежние файлы лаунчер сохраняет в PackConflicts. Миры и личный язык игры не входят в этот путь.

## Управление

`launcher/controls-preset.txt` содержит только назначения клавиш и применяется по явному действию в лаунчере. Он не меняет язык, графику и остальные личные настройки; готовый `options.txt` не поставляется. Краткая раскладка и ограничения проверки описаны в [памятке управления](launcher/controls-guide.md).

Пресет содержит 148 ожидаемых имён: 90 назначений и 58 свободных действий. Проверены штатный парсер лаунчера, допустимость токенов настоящим Forge и отсутствие новых консервативных пересечений. 53 оставшиеся пары сохраняют прежние авторские назначения. Реестр полного текущего клиента с 97 JAR и сохранение раскладки после его перезапуска отдельно не измерены. Точные JAR и происхождение ожидаемых имён закреплены в `tools/keybinds/stock.json`.

JAR, настройки модов, квесты и миры этим изменением не затрагиваются. Safety не требует новых профилей: новых модов, способностей, путей записи мира или изменения разрешений не добавлено.

## Воспроизведение и выпуск

Нужны Python 3.12 и JDK для сборки helper. Из корня репозитория:

```text
python tools/restore_distribution.py --pack .
python tools/build_mod_pages.py --verify-only
python tools/keybinds/check_preset.py
python -m unittest discover -s tools -p "test_*.py"
python -m unittest discover -s tools/quests -p "test_*.py"
python tools/quests/generate.py --verify-only
python tools/restore_distribution.py --pack . --verify-only
python tools/generate_manifest.py --pack . --out dist --revision <commit-sha>
python tools/generate_manifest.py --pack . --out dist --verify-only
```

Команда сборки helper и её проверки приведены в `tools/world-type-lock/README.md`. Locks отклоняют изменённые файлы и неизвестные JAR; личные игровые папки для подготовки не используются. Библиотечные ссылки, вложенные библиотеки и происхождение превью описаны в `library/README.md`.

Workflow публикует все payload в rolling release `pack-latest` перед `pack-manifest.json`. Запись в каталоге LANMinecraft добавляется только после проверки первого опубликованного манифеста. Новый EXE лаунчера для этой карточки не нужен.

## Проверки

Фактические результаты клиентского запуска, мира, встроенного LAN и ограничений описываются в `TESTING-STATUS.md`. Dedicated server является отдельным QA: исходная сборка имеет подтверждённый сбой Copperative при загрузке на dedicated side; это не результат проверки встроенного сервера клиента. Подробности и воспроизводимый стенд находятся в `tools/qa-server/README.md`. Непроведённые сценарии не считаются успешными.
