# Управление Caves and Dungeons

Пресет меняет только назначения клавиш. Язык игры, графика и остальные личные настройки сохраняются. После явного применения можно изменить отдельные клавиши в обычном меню Minecraft.

| Действие | Клавиша |
| --- | --- |
| Движение, прыжок, приседание, бег | W/A/S/D, пробел, левый Shift, левый Ctrl |
| Инвентарь, предмет во второй руке, выбросить | E, F, Q |
| Панель быстрого доступа | 1–9 |
| Квесты, команда FTB | Ё / grave accent, K |
| Карта, настройки карты | M, ] |
| Рюкзак, действие рюкзака в инвентаре | B, H |
| Первое и второе улучшение рюкзака | ; и ' |
| Curios | G |
| Особая способность Alex’s Caves | C |
| Бур Glowroot | J |
| Приближение | Z, удерживать |
| Рецепты, применения, закладка JEI | R, U, I, когда указатель находится над предметом |
| Сменить плечо камеры, свободный взгляд | X, левый Alt |
| Смена панели Quark, вариант блока, фиксация поворота | N, V, запятая |
| Управление камерой Exposure | [ |
| Показ информации Waila | F6 |
| Способность Helium Flamingo | F7 |
| Выбор шейдерпака, перезагрузить шейдеры, переключить шейдеры | O, F10, F8 |
| Режим камеры Quark | F12 |

Ванильные F2, F5, F11, L, T, Tab и / сохранены. Обычные клики и переходы JEI, а также сортировка рюкзака средней кнопкой мыши сохранены. Они работают в своих экранах; такое авторское совместное использование мыши не является назначением двух новых боевых способностей на одну кнопку.

Дополнительные положения камеры вынесены на цифровой блок: 4/6 — влево/вправо, 8/2 — ближе/дальше, 9/3 — выше/ниже. Там же 0 открывает Waila, 1 переключает показ жидкости, 5 переключает очки ночного зрения, 7 — Universal Attractor. Эти дополнительные назначения можно поменять на клавиатуре без цифрового блока; основные движение, меню, рюкзак, бур и особая способность его не требуют.

Без назначения оставлены социальное меню, сохранение/загрузка творческой панели, редактор Structure Gel, отладочные переключатели, отдельные эмоции Quark, дублирующие способы выбора вида камеры, прямые клавиши картографических фильтров и улучшения рюкзака 3–5. Это освобождает клавиши для обычной игры; нужные редкие команды можно назначить в меню управления.

Пресет содержит 148 ожидаемых имён: 146 из технического снимка с 93 неизменившимися JAR и две регистрации новых FTB Quests/Teams. 90 назначены, 58 оставлены свободными. Текущая сборка содержит 97 JAR; окончательное подтверждение её реестра и сохранения раскладки после перезапуска ещё не выполнено. Проверка штатным парсером лаунчера и настоящим Forge 47.4 приняла все 148 строк; консервативная проверка не нашла новых пересечений относительно исходных назначений.
