# Данные библиотеки

Описания относятся к авторской Caves and Dungeons 1.4, CurseForge project
971867 / file 6164816. Названия, версии и mod ID читаются из фактических JAR.
Связи аддонов подтверждены страницами проектов, а не только зависимостями:
Alex's Caves: Trimmed! и Stuff & Torpedoes расширяют Alex's Caves; Stronghold
Rework относится к Dungeons and Taverns; Botany Trees расширяет Botany Pots.

Пресет `caves_and_dungeons:modded_mines` с русским названием «Шахты с Модами»
подготовлен для версии лаунчера. Он сохраняет текущую авторскую обычную
генерацию и правила бункера/солнца, ограничивая выбор при создании нового мира.
Это собственный пресет и ограничение интерфейса создания, а не утверждение
о точной реализации мира из ролика Иванчелы. Существующие и импортированные
миры не блокируются и не преобразуются.

`preview.jpg` получен из официальной галереи сборки, снимок Primordial caves.
Источник, SHA256 исходного PNG и результирующего JPEG находятся в
`preview-source.json`. Менялся только формат изображения.

`mod-pages.json` воспроизводится командой `python tools/build_mod_pages.py`.
Активный состав берётся из `tools/distribution-lock.json`, исходный авторский
снимок сохраняется отдельно в `tools/upstream-lock.json`. Каждый JAR связан
с официальной страницей через точный SHA256 активной записи. Без активного
lock инструмент может проверить исходный снимок, но CI выпуска требует именно
активный lock. Для Illuminative сохранён подтверждённый адрес
из авторского экспорта с `available:false`: текущие project/file API не
возвращают метаданные, а доступность страницы подтвердить не удалось. Это
не утверждение об удалении проекта; одноимённая чужая страница не подставлена.

Вложенные Forge-моды читаются из объявленных записей JarJar вместе с основным
модом. Повторно встроенная библиотека показывается один раз; из вложенных
вариантов указывается новая объявленная версия. Конфликтующие имена и ссылки
останавливают публикацию. Простые Java-модули с автоматически сгенерированной
Fabric-разметкой не выдаются за загружаемые Forge-моды.

Поле `modPages` активной записи задаёт отдельные проверенные источники вложенных
mod ID. ExpandAbility использует свою страницу CurseForge; MixinExtras свой
репозиторий LlamaLad7; KumaAPI канонический репозиторий TwelveIterations/KumaAPI;
XaeroLib свою страницу CurseForge. У MixinExtras не найдена самостоятельная
страница CurseForge или Modrinth, а KumaAPI автор поставляет только как
встроенную библиотеку. Их ссылки ведут на собственные исходники, не на страницу
основного мода. Источник XaeroLib прямо поясняет встроенную поставку на новых
версиях Minecraft. Вложенные хеши и модульные ID фиксируются при подготовке
активного состава; неизвестный вложенный ID требует нового проверенного адреса.

CI и локальная проверка поставки используют
`python tools/restore_distribution.py --pack .`, а проверка без загрузок —
`python tools/restore_distribution.py --pack . --verify-only`. Инструмент не
восстанавливает старую карту или иной заменённый JAR из исторического lock:
он скачивает только отсутствующие активные файлы с закреплёнными хешами.
Изменённый существующий файл, неизвестный JAR или устаревший supportFile
останавливают проверку. Нужные supportFiles уже должны присутствовать в
checkout; их инструмент не перезаписывает.

После проверки активной поставки CI устанавливает Microsoft JDK 25.0.2 и
воспроизводит helper из исходников командой
`python tools/world-type-lock/build_helper.py --output artifacts/world-type-lock --verify-installed mods/cad-world-type-lock-1.0.0.jar`.
Результат пишется только в `artifacts`, а его SHA256 должен совпасть с уже
проверенным JAR в поставке. Непроверенная пересборка не подменяет активный файл.

Собственный helper создания мира использует официальный источник этого репозитория:
https://github.com/MarkZamore/Caves-and-Dungeons. Его запись хранится отдельно
от исходного авторского lock в `tools/local-mods.json` и также включается
в активные `supportFiles`. Фактический mod ID, размер и SHA256 должны совпасть
с проверенным JAR; допустим только один `cad_world_type_lock`:

```json
{
  "schemaVersion": 1,
  "files": [
    {
      "path": "mods/cad-world-type-lock-1.0.0.jar",
      "sizeBytes": 0,
      "sha256": "точный SHA256 собранного JAR",
      "modIds": ["cad_world_type_lock"],
      "websiteUrl": "https://github.com/MarkZamore/Caves-and-Dungeons"
    }
  ]
}
```

Показанные размер и SHA256 служат только описанием формата; реальная запись
должна содержать проверенные значения. Генератор отклоняет несовпадение
состава mod ID, размера или хеша и любой неизвестный JAR.
