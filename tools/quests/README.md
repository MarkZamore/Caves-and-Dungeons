# Русский квестбук без наград

`generate.py` создаёт книгу FTB Quests Forge 2001.4.22 для фактических JAR сборки. Формат книги — 13. JSON-разметка файлов `.snbt` принимается SNBT-парсером FTB Library; иконки и предметные задания используют формат Minecraft 1.20.1 без `components`.

Четыре основные главы ведут от бункера и железа через обработку алмазов Spelunkery и изучение пещер к Краю. Короткие подсказки написаны для этой сборки, включая оба авторских пути получения огненного порошка без Незера. Основа проверки рецептов — `scripts/recipes_for_CaD.zs`, фактические advancement JSON и рецепты установленных модов. Компасы не навязываются в начале, поскольку авторские рецепты усложнены.

Дополнительные главы охватывают каждое зарегистрированное модовое достижение с `display`, в том числе скрытые достижения. Крупная ветка Alex’s Caves разделена по шести биомам. Заголовки и описания передаются как исходные Minecraft Component JSON, поэтому используют те же переводы, что экран достижений. Последним слоем читается `tools/world-type-lock/src/lock/resources/builtin/russian-advancements/data`: mandatory server-data pack высшего приоритета содержит адресное исправление единственного literal display, не поддерживавшего языковые ресурсы.

В нативном baseline клиенте загружены 565 display вместо 567 в исходных JAR: `quark:influence` и `quark:pat_potato` не зарегистрированы. Их условия `quark:advancement_flag` с флагами `candle_influencing` и `tiny_potato` ложны в согласованном составе. Эти две цели исключены из активной книги, а переводы сохранены в языковых ресурсах. `runtime-exclusions.json` фиксирует точные условия, SHA256 Quark и основание проверки; это не вывод из названий TOML-параметров. Итого книга содержит 472 задания, 468 advancement tasks и все 455 реально зарегистрированных модовых достижений.

Дерево родителей определяет расположение дополнительных заданий, а заголовок родителя повторяется в тексте. Оно не становится искусственным условием: parent у достижения часто определяет только положение в меню, а отдельные исходные достижения требуют закрытого Незера или опасной поверхности. Эти пункты остаются справочными, не блокируют основной маршрут и явно отмечены общей памяткой. Основные задания имеют обычные зависимости, но все описания открыты для чтения.

В книге 0 наград. Нет reward tables, командных/предметных/XP-наград, аварийных предметов и выпадения ящиков. Три предметные проверки ничего не расходуют и не блокируют дальнейшие задания: в прежнем мире ингредиенты уже могли быть потрачены. Единственная ручная галочка — вступительная памятка; остальные задания проверяют реальные достижения или инвентарь.

## Воспроизведение

Из корня сборки:

```text
python tools/quests/generate.py
python tools/quests/generate.py --verify-only
python -m unittest discover -s tools/quests -p "test_*.py"
# При игровом QA: сверить цели с фактическим ServerAdvancementManager.
python tools/quests/generate.py --verify-only --runtime-snapshot artifacts/<qa>/evidence/native-content.json
```

Генерация детерминирована; ID зависят от стабильного advancement ID, поэтому добавление нового мода не сбрасывает прежние задания. Проверка отклоняет потерянные/повторённые достижения, отсутствующие ссылки, циклы, устаревшие и неизвестные SNBT. Замена закреплённого Quark требует повторной проверки исключений. После изменения конфигов или состава сверка `--runtime-snapshot` обнаруживает как отсутствующие цели книги, так и вновь включённые модовые достижения; список исключений нельзя переносить вслепую. Книга управляется узким правилом `config/ftbquests/quests/**` в `launcher/pack-owned.txt`; личный `options.txt` и игровые данные в ownership не входят. Изменённую локальную книгу лаунчер сохраняет в `Personal/PackConflicts` перед обновлением.

Вспомогательные тесты проверяют полноту, отсутствие наград, соответствие рецептов, зависимости главного пути и Components. Они не заменяют загрузку книги, работу переводов и автоматическое выполнение заданий настоящим клиентом.

## Источники и пример

- [Официальная Caves and Dungeons 1.4](https://www.curseforge.com/minecraft/modpacks/caves-and-dungeons/files/6164816): жизнь в пещерах, опасная поверхность, закрытый Незер и выход через Край.
- [Исходники TerraFirma Rebirth 2](https://github.com/GranniXXie/TerraFirmaRebirth): пример разделения на основной маршрут и дополнительные занятия, короткие пояснения и ветки. Для сравнения изучена установленная книга `config/ftbquests/quests` версии Rebirth 2. Тексты, награды и несовместимые с 1.20.1 item components из неё не копировались.
- [FTB Quests AdvancementTask, ветка 1.20.1/main](https://github.com/FTBTeam/FTB-Quests/blob/1.20.1/main/common/src/main/java/dev/ftb/mods/ftbquests/quest/task/AdvancementTask.java): `advancement` с пустым `criterion` проверяет весь сохранённый AdvancementProgress, включая достижения, полученные до установки книги. Проверка выполняется автоматически раз в пять тиков.
- [FTB Quests TextUtils](https://github.com/FTBTeam/FTB-Quests/blob/1.20.1/main/common/src/main/java/dev/ftb/mods/ftbquests/util/TextUtils.java): native Components в строках заголовков и описаний.

Новые FTB JAR и их Safety-анализ перечисляются владельцем активной поставки в общем `tools/UPDATE-NOTES.md` и distribution lock, не в историческом upstream lock.
