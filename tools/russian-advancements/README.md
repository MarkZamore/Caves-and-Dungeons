# Русские достижения

Переводы встроены в обязательный helper `cad_world_type_lock`: они загружаются вместе со сборкой без ручного включения ресурспака. Исходники находятся в `tools/world-type-lock/src/lock/resources/assets/*/lang/ru_ru.json`. Добавлены 210 строк: отсутствующие и оставшиеся английские заголовки/описания, русские имена корневых вкладок и три смешанные строки с английскими словами. Доступные авторские русские переводы остальных достижений сохранены.

У `nova_structures:adventure/tavern_quest` автор записал английский текст непосредственно в display, поэтому одной языковой строки недостаточно. Его JSON в helper заменяет только `display.title` и `display.description` на переводимые компоненты. Он находится в `builtin/russian-advancements/data/` и зарегистрирован как обязательный `TOP SERVER_DATA` pack `cad-russian-display`. Это сохраняет приоритет над авторским JSON и для старых миров с сохранённым порядком datapacks. Критерии, родитель, значок и все остальные поля остаются исходными. `en_us` содержит прежние две английские строки, поэтому смена языка обратима. Авторские JAR не перепаковываются.

## Воспроизводимая проверка

После восстановления активной поставки:

```text
python -m unittest discover -s tools -p test_russian_advancements.py
python tools/russian-advancements/audit.py --pack . --output artifacts/russian-advancements/mod-audit.json
```

Аудит читает настоящие JAR, вложенные JarJar, поставляемые ZIP-ресурспаки, исходные ресурсы helper и затем его обязательный builtin datapack. Он обходит все display, включая скрытые достижения, а также вложенные `extra` и `with`. В согласованной поставке 567 display: 457 модовых и 110 Minecraft. Добавленные FTB Library/Teams/Quests не добавляют display-достижений. JSON-отчёт содержит точные ID, компоненты, ожидаемые русские строки и SHA256 входных файлов.

Это число исходных JSON, а не обещание одинакового количества активных достижений: Quark при нативной загрузке исключает `quark:influence` и `quark:pat_potato`. Их русские строки также подготовлены, но квестбук не требует эти недоступные достижения. Состав реального `ServerAdvancementManager` проверяется отдельно.

Файл русского языка Minecraft поставляется через официальный индекс assets и отсутствует в клиентском JAR. Для полной офлайн-проверки передайте его фактический файл:

```text
python tools/russian-advancements/audit.py --pack . --vanilla-ru <assets-object-ru_ru.json> --output artifacts/russian-advancements/full-audit.json
```

Для Minecraft 1.20.1 индекс `5.json` указывает объект `2ccfaf991e41f12575364b5e0033c7b85d478348` (SHA1). Команда с этим объектом проверяет все 567 display; без него отчёт честно оставляет 110 стандартных достижений непроверенными. Название стандартной корневой вкладки также русифицировано: «Майнкрафт».

Проверки дополнительно сравнивают исходный и изменённый JSON достижения целиком, исключая только два текстовых поля, и сохраняют английский fallback. Они не проверяют реальный приоритет resource packs. Фактическую загрузку переводов, нативный `LanguageManager`, список `ServerAdvancementManager` и смену `ru_ru`/`en_us` проверяет клиентский стенд; его результаты фиксируются отдельно в `TESTING-STATUS.md`.
